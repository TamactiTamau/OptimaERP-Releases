## 💻 Installation Instructions

### 1. 🪟 Windows Installation
1. Download `Optima_ERP_Setup.exe`.
2. Double-click the downloaded file and follow the setup wizard.
3. Choose your setup mode:
   - **Server / Standalone:** Installs the local database service for single-PC or main server office installations.
   - **Client Workstation:** Connects to an existing office server over your local Wi-Fi or LAN.

### 2. 🍏 macOS Installation
1. Download `OptimaERP-macOS-arm64.dmg`.
2. Double-click the `.dmg` file to open it.
3. Drag the **Optima ERP** icon into your **Applications** folder.
4. Launch Optima ERP from your Launchpad or Applications folder.

### 3. 🐧 ChromeOS Installation (1-Click Install)
1. Turn on the Linux development environment on your Chromebook:
   - Go to **Settings** ➔ **Developers** ➔ **Linux development environment** ➔ click **Turn on**.
2. Download `optima-erp_amd64.deb`.
3. Open the **Files** app on your Chromebook, right-click `optima-erp_amd64.deb`, and choose **"Install with Linux"**.
4. Once completed, **Optima ERP** will appear directly in your ChromeOS App Launcher!

### 4. 🐧 Linux (Ubuntu, Debian, Linux Mint)
Double-click the downloaded `optima-erp_amd64.deb` or run:
```bash
sudo dpkg -i optima-erp_amd64.deb
sudo apt-get install -f
```

### 5. 🚀 Universal Linux (Portable .AppImage)
For Fedora, Arch Linux, openSUSE, and any other distribution:
```bash
chmod +x OptimaERP-x86_64.AppImage
./OptimaERP-x86_64.AppImage
```

Every release includes a `SHA256SUMS.txt` file containing cryptographic hashes of all installer binaries. You can verify the integrity of your download by running:
```bash
sha256sum -c SHA256SUMS.txt
```
